# 课程项目五原始证据索引

本目录保存 SmartFan 2.0 课程项目相关的原始照片、视频、测量记录和证据清单。当前目录结构是归档规则，不代表证据已经采集或上传。

## 子目录

| 目录 | 应保存的证据 |
|---|---|
| 00_before_experiment/ | 实验前设备全景、铭牌、包装、初始状态 |
| 01_hardware_inspection/ | ESP32、传感器、驱动模块、电源及接口的原始照片 |
| 02_structure_and_assembly/ | 结构观察、拆解（如安全且实际进行）、组装过程分步照片 |
| 03_chip_identification/ | 芯片丝印近照、板卡正反面照片 |
| 04_wiring_and_testing/ | 接线前后照片、测试视频、仪器读数和日志 |
| 05_system_demonstration/ | 系统演示、真实运行状态和界面证据 |

## 证据规则

1. 原始文件保持原样；裁剪、加箭头或标注的版本另存。
2. 使用实验编号命名，例如 EXP-001-01-all-components-original.jpg。
3. 每项证据在对应实验记录中登记拍摄日期、内容、文件名和用途。
4. 不将示意图当作实物照片，不将计划中的实验写成已完成。
5. 大文件若存放在外部平台，需在实验记录中保留原始文件名、大小（如有）、存储位置和访问说明。
