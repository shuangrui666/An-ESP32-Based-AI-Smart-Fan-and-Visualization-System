# Hardware Inspection Evidence

本目录用于保存 SmartFan 2.0 课程项目的真实硬件照片。照片来自用户上传的原始 JPG 文件；本次仅调整仓库内文件名，不修改图片内容。

## 文件命名与核验原则

- `hardware_photo_01.jpg` 至 `hardware_photo_07.jpg` 按原始文件名中的拍摄时间先后编号。
- 当前编号仅用于稳定引用和归档，不代表照片已经确认属于开发板正面、背面、DHT11、USB 风扇或其他部件。
- 在逐张查看原图并确认画面内容之前，不猜测照片主体，不把“待核验”写成“已确认”。
- 后续完成视觉核验后，再将通用编号改为具体硬件名称，并在本文件中补充可见标识、照片用途和核验结论。
- 原始图片内容保持不变；Git 历史保留本次重命名前的文件路径。
