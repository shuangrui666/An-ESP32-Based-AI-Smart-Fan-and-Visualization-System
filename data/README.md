# 项目数据与成本资料

本目录保存真实硬件清单、BOM 成本核算及升级增量器件数据。当前已把可识别的实物和用户确认参数录入表格；未知价格、数量和电气参数保持空白或标记待核实，不以估算冒充实际成本。

## 文件

- component_inventory.csv：实际元器件、模块和设备清单。
- BOM_cost_analysis.csv：BOM 成本核算工作表（CSV 版本，可用 Excel 打开）。
- incremental_components.csv：智能化升级新增器件及课程预算范围核算。

## 当前录入范围

- ESP32-S3 开发板：识别为 YD-ESP32-S3 Classic V1.0；购置成本是否单独计入、套件分摊金额尚未提供。
- 板载模组：可辨认丝印 ESP32-S3-WROOM-1，完整后缀未知；作为开发板组成部分记录，避免重复计价。
- DHT11 模块：型号由用户确认；购置价格尚未提供。
- USB 风扇：商家确认额定值 5 V / 1 A；实际购买价格尚未提供。
- 杜邦线：用户确认已有，具体数量、规格和历史成本尚未清点。
- ESP-Claw 套件其他器件：尚未逐项清点，不能虚构条目。

## 数据填写规则

1. 记录完整型号、规格、数量、来源（自购/借用/套件/已有）。
2. 区分实际支付价格、公开零售价格、批量报价和估算值。
3. 报价记录供应商、商品/型号链接、查询日期、批量数量区间、币种和单位。
4. 未确认数据留空或标记 pending_verification，不要编造。
5. BOM 总成本与课程要求的 20 元增量器件预算分别核算。
6. 板载模组若已包含在开发板价格中，不重复计价。
7. incremental_components.csv 暂无已确认的新增采购条目；待确认驱动方案和缺失器件后，再登记实际拟购/已购项目。
8. 价格字段只有取得订单、收据或可追溯报价后才填写；若课程要求按批量核算，必须注明批量数量和价格来源。
