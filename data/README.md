# 项目数据与成本资料

本目录保存真实硬件清单、BOM 成本核算及升级增量器件数据。表格初始模板不代表已经完成清点或询价。

## 文件

- component_inventory.csv：实际元器件、模块和设备清单。
- BOM_cost_analysis.csv：BOM 成本核算工作表（CSV 版本，可用 Excel 打开）。
- incremental_components.csv：智能化升级新增器件及 20 元预算核算。

## 数据填写规则

- 记录完整型号、规格、数量、来源（自购/借用/套件/已有）。
- 区分实际支付价格、公开零售价格、批量报价和估算值。
- 报价记录供应商、商品/型号链接、查询日期、批量数量区间、币种和单位。
- 未确认数据留空或标记 pending_verification，不要编造。
- BOM 总成本与课程要求的 20 元增量器件预算分别核算。
