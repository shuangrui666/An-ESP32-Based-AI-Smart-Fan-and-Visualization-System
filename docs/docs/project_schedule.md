# SmartFan 2.0 Development Schedule

## 1. Development Overview

The project will be developed in stages. Each stage will have specific tasks and verifiable outputs.

The schedule may be adjusted according to hardware availability, experimental results and instructor requirements.

## 2. Development Stages

| Stage | Main Tasks | Expected Deliverables |
|---|---|---|
| 1. Project Preparation | Create repository, document project concept and technical route | README and project documents |
| 2. Hardware Verification | Inspect ESP-Claw kit, identify sensors and verify fan specifications | Hardware inventory and component records |
| 3. Hardware Development | Connect ESP32 and sensors, test fan control | Basic working hardware prototype |
| 4. Backend Development | Develop Python backend and Wi-Fi communication | Data receiving and control APIs |
| 5. AI Development | Prepare dataset, train and evaluate decision tree model | Model, evaluation results and charts |
| 6. Dashboard Development | Build responsive monitoring and control interface | Web visualization dashboard |
| 7. System Integration | Integrate hardware, backend, AI and dashboard | Integrated prototype |
| 8. Experimental Testing | Test control, communication and stability | Experimental records and analysis |
| 9. Final Delivery | Organize code, data, documentation and presentation | Final GitHub repository and project report |

## 3. Task Details

### Stage 1: Project Preparation
- Create the GitHub repository.
- Complete README.md.
- Write the project proposal.
- Write the development schedule.
- Design the initial system architecture.

### Stage 2: Hardware Verification
- Inspect the ESP-Claw kit.
- Identify the ESP32 development board.
- Confirm available sensors and modules.
- Record the fan voltage, current and motor type.
- Confirm available laboratory tools.

### Stage 3: Hardware Development
- Set up the ESP32 development environment.
- Test temperature and humidity collection.
- Test PIR motion detection.
- Select a suitable motor driver.
- Test fan control safely.

### Stage 4: Backend Development
- Set up the Python environment.
- Develop a Flask application.
- Implement sensor data receiving.
- Implement device status and control interfaces.
- Store experimental records.

### Stage 5: AI Development
- Collect and organize training data.
- Define model inputs and output labels.
- Train a Decision Tree Classifier.
- Evaluate the model.
- Visualize the decision tree and confusion matrix.
- Connect predictions to the control system.

### Stage 6: Dashboard Development
- Create the dashboard layout.
- Display real-time temperature and humidity.
- Display fan operating status and mode.
- Add historical time-series charts.
- Display AI recommendations.
- Implement manual and automatic control.

### Stage 7: System Integration
- Connect the ESP32 to the backend.
- Connect the AI model to the control process.
- Connect the dashboard to the backend.
- Implement offline fallback control.
- Check the consistency of displayed and actual device states.

### Stage 8: Experimental Testing
- Conduct environmental monitoring tests.
- Conduct motion detection tests.
- Conduct fan control tests.
- Conduct network disconnection tests.
- Evaluate system stability.
- Record and analyze results.

### Stage 9: Final Delivery
- Complete source code and documentation.
- Organize experimental data and charts.
- Save prototype photos and videos.
- Prepare the final report.
- Prepare the demonstration presentation.
- Review the GitHub repository.

## 5. Completion Criteria

A task will be marked as completed only when its output exists and has been checked.

Experimental functions must be supported by actual test records. Planned functions must not be presented as completed functions.

## 6. Schedule Maintenance

The project schedule will be updated as development progresses.

Changes in hardware availability, technical decisions, testing results and project requirements will be documented.
