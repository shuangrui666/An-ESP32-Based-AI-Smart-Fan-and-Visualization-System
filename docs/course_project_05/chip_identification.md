## 2. 重要术语区分

- **开发板型号**：YD-ESP32-S3 Classic V1.0，用于识别整块开发板。
- **模组丝印**：ESP32-S3-WROOM-1，表示板载无线模组系列；目前没有足够依据填写完整后缀。
- **传感器模块**：DHT11 是用户确认的模块型号。本记录不把它误写成 ESP32 芯片。
- **主控芯片完整订货型号**：目前未从清晰芯片/模组资料中确认，不填写猜测型号。
