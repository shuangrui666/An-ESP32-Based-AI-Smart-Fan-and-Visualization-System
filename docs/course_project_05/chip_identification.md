## 溯源步骤

1. 拍摄芯片清晰近照，保留未经标注的原始照片。
2. 逐字符记录丝印，不根据模糊字符猜型号。
3. 检索芯片制造商官方数据手册或产品页面。
4. 对比封装、引脚数、板卡用途等信息。
5. 记录资料链接、访问日期和判断依据。
