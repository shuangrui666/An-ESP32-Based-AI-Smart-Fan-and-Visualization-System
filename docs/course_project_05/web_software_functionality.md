- 项目：SmartFan 2.0
- 对应课程评分：智能化系统展示、软件界面与功能实现
- 状态：软件功能已实现并有部分 API/代码验证；网页截图和端到端实机证据待补
- 证据目录：[06_web_interface_and_software](../../evidence/course_project_05/06_web_interface_and_software/README.md)

## 1. 系统组成

网页前端由 HTML、CSS、JavaScript 和 ECharts 构成；Flask 后端提供传感器数据接收、状态查询和风扇命令接口；ESP32-S3 固件负责读取传感器、通过 Wi-Fi 与后端通信，并驱动 MOSFET 控制风扇。

| 子系统 | 功能 | 实现情况 |
|---|---|---|
| 数据可视化 | 温度、湿度数据显示及趋势图表 | 前端已实现 |
| 设备状态 | 展示设备在线状态及相关运行信息 | 前端/后端已有实现；状态真实性需以硬件联调核验 |

## 3. 运行步骤

1. 在 `backend` 目录安装 `requirements.txt` 并运行 `python app.py`。
2. 在仓库根目录运行 `python -m http.server 8080 --directory frontend`。
3. 浏览器打开 `http://localhost:8080`。
4. 确认前端 `BACKEND_URL` 指向当前 Flask 服务地址。
5. 若测试 ESP32 通信，确认 ESP32 与 Flask 主机处于可互通网络。

详细命令、代码入口和测试截图清单见 [网页证据归档说明](../../evidence/course_project_05/06_web_interface_and_software/README.md)。
