# Frontend Historical Archive

## Purpose

This directory preserves historical frontend source snapshots
from the SmartFan project.

These files are archived for development traceability and are
not the current production frontend source.

## Archived Files

| File | Description |
|---|---|
| index_before_fan_status.html | HTML snapshot before fan status feedback and expanded control UI |
| app_before_fan_status.js | JavaScript snapshot before control mode and command status enhancements |

## Historical Context

The archived snapshots preserve an earlier stage of frontend development.

Subsequent development introduced:
- Fan status display
- Actual running gear feedback
- Automatic/manual control mode switching
- Manual gear control from 0 to 5
- Command status polling
- Relative backend API paths for deployment

## Important

The current frontend implementation remains in `frontend/`.

The archived files are historical evidence and should not be
used as the current production entry point.
