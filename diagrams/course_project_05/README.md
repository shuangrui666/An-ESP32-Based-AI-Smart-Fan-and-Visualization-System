# 课程项目五图纸索引

本目录保存由真实硬件信息和可追溯依据支持的图纸。所有图纸必须区分实物确认内容、设计方案内容和待核实内容。

| 图纸 | 用途 | 状态 |
|---|---|---|
| hardware_structure.png | 智能风扇系统硬件结构/爆炸示意 | 待绘制 |
| power_supply_diagram.png | 实际供电路径框图 | 待核实后绘制 |
| control_block_diagram.png | 传感器、ESP32、驱动器和负载控制关系 | 待核实后绘制 |
| original_board_connection_points.png | 实际板卡接口与接入点标注 | 待实物确认 |
| control_state_diagram.png | 自动/手动、风扇状态及异常处理逻辑 | 待设计 |

示意图不得冒充实物拆解照片；未测量或未查证的线路不得绘制成已确认连接。
