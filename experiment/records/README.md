# 独立实验记录

每次独立实验建立一个 Markdown 文件，推荐路径：

`records/YYYY-MM-DD/EXP-NNN-short-description.md`

文件名中的日期必须是真实实验日期。实验编号全项目唯一。可以复制 [实验记录模板](EXPERIMENT_RECORD_TEMPLATE.md) 开始填写。

## 证据文件命名

推荐使用：

- `EXP-NNN-01-overview.jpg`
- `EXP-NNN-02-connection.jpg`
- `EXP-NNN-03-serial-log.txt`
- `EXP-NNN-04-measurements.csv`

文件名应能对应实验编号和证据内容。图片和数据的说明写在对应实验记录中。

## 记录要求

- 实验前写目的、设备、条件和步骤。
- 实验中记录实际操作、时间、读数和异常。
- 实验后写结果、结论、限制和后续计划。
- 未确认的信息标记“待核实”。
- 没有发生的实验不得提前填写结果。
- 失败过程及原始证据应保留。
