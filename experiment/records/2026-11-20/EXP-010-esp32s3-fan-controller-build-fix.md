## 5. 验证范围与限制

### 已验证

- 当前 PlatformIO 构建目标能够成功编译。
- 本次报告中的 LEDC API 兼容性问题、PIR 引脚未定义问题及 5 处格式字符串警告已处理。
- 构建产物 `firmware.bin` 已生成。
- 编译报告显示 RAM 和 Flash 静态占用分别为 14.4% 和 30.5%。

### 尚未由本次编译证明

- 固件是否已经烧录到 ESP32-S3 并成功启动。
- LEDC PWM 是否在实际 GPIO 上输出正确波形。
- PWM 输出是否能正确驱动 MOSFET 模块。
- MOSFET 是否能可靠控制 5V USB 风扇。
- PIR 触发后是否确实启动风扇。
- 最后一次有效 PIR 触发后是否准确延时 60 秒关闭风扇。
- 60 秒计时期间再次触发是否正确刷新计时。
- 完整 PIR → ESP32-S3 → MOSFET → 风扇自动控制链路是否通过集成测试。

因此，本实验结论仅为“代码编译验证通过”，不代表风扇自动控制功能已经完成或通过硬件验收。
