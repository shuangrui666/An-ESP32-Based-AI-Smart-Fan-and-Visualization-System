# EXP-009：PIR 硬件信号测试

- **日期**: 2026-11-20
- **状态**: 硬件测试完成；PIR 信号读取初步成功
- **目标**: 在确认电气安全的前提下，实际烧录 PIR 测试程序并观察 GPIO5 的信号变化
- **测试程序**: `pir-read-test`
- **烧录命令**: `pio run -e pir-read-test -t upload --upload-port COM6`
- **烧录结果**: SUCCESS，耗时 12.57 秒，固件写入后 Hash 校验通过

---

## 一、实验目的

验证 PIR 模块实际输出信号能否被 ESP32-S3 GPIO5 正确读取，观察信号变化模式是否符合人体感应特征。

**本次测试范围**：
- 仅测试 PIR OUT 引脚信号读取
- 不控制 MOSFET，不驱动风扇
- 不进行灵敏度、距离、角度标定

---

## 二、硬件与软件环境

### 硬件配置

| 组件 | 规格/型号 | 连接方式 |
|---|---|---|
| 开发板 | ESP32-S3 | YD-ESP32-S3 Classic V1.0 |
| PIR 模块 | HC-SR501 | 用户确认型号 |
| PIR VCC | ESP32 5V 输出 | 红色导线 |
| PIR GND | ESP32 GND | 黑色导线 |
| PIR OUT | ESP32 GPIO5 | 黄色导线 |
| 串口 | COM6 | 115200 baud |

### 软件配置

| 项目 | 配置 |
|---|---|
| 编译环境 | PlatformIO, ESP32-S3, Arduino 框架 |
| 测试环境 | `[env:pir-read-test]` |
| 源码文件 | `src/test_pir_main.cpp` |
| 采样间隔 | 200 ms |
| 日志间隔 | 每 2 秒输出当前电平状态 |

### 安全确认

- PIR 模块供电使用 ESP32 5V 输出
- PIR OUT 连接 GPIO5（数字输入引脚）
- 测试期间 MOSFET 已断开，风扇未接入测试电路
- 测试程序只读取 GPIO5，不写任何输出引脚

---

## 六、静止状态观察

**测试操作**：用户停止移动并静坐观察约 30 秒。

**观察结果**：
- 时间范围：uptime 162s 至 200s（约 38 秒）
- 输出频率：每 2 秒一次 `Current raw level: LOW`
- 期间状态：持续 LOW，**没有 HIGH 变化**

**结论**：静止状态下 PIR 输出稳定在 LOW 电平，未触发信号。

## 七、测试结果分析

### 已验证事项

| 事项 | 证据 |
|---|---|
| ESP32-S3 成功烧录 PIR 测试程序 | Hash 校验通过，串口输出正常 |
| GPIO5 能够正确读取数字电平 | 观察到明确的 HIGH/LOW 变化 |
| PIR 模块输出信号符合预期 | HIGH 持续约 2.6-2.8 秒，LOW 持续约 5-6 秒 |
| 静止状态下输出稳定 LOW | 38 秒连续观察无 HIGH 变化 |
| PIR 信号读取功能初步成功 | 8 次完整 HIGH/LOW 周期被正确记录 |

| 环境干扰测试 | 未测试光线、温度、振动等环境因素的影响 |

## 八、结论与限制

### 结论

**PIR 信号读取测试取得初步成功**：

1. ESP32-S3 成功读取 GPIO5 数字电平
2. GPIO5 多次出现 HIGH/LOW 变化（8 次完整周期）
3. 静止观察期间持续 LOW，无误触发
4. 信号模式符合 PIR 人体感应传感器典型特征

### 限制

**本次测试不能证明**：

1. 所有 HIGH 信号均由人体移动引起（未做对照实验）
2. PIR 检测距离、角度、灵敏度已完成标定（未进行标定测试）
3. 风扇自动控制已经实现（测试程序明确不控制风扇）
4. MOSFET 驱动已经通过测试（MOSFET 在测试期间已断开）
