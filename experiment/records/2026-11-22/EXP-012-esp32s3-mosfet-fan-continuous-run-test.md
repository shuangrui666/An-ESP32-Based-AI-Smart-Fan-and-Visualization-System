# EXP-012：ESP32-S3 GPIO6 / MOSFET 风扇连续运行验证

- 实验编号：EXP-012
- 实验日期：2026-11-22
- 记录创建日期：2026-11-22
- 实验名称：ESP32-S3 通过 MOSFET 模块驱动 5V USB 风扇连续运行测试
- 实验状态：completed（基本开关控制与连续运行现象已观察；电气测量及调速能力待验证）
- 记录性质：依据本次对话中的用户操作反馈和测试程序内容整理；未取得独立照片、视频或原始串口日志文件。

## 1. 实验目的

验证 ESP32-S3 的 GPIO6 能否通过 MOSFET 驱动模块控制 5V USB 风扇，并确认将 PWM 占空比设置为 100% 后，风扇能否持续运行。

本次测试是独立测试程序验证，不代表正式 SmartFan 固件已经完成风扇控制集成。

## 2. 实验设备与连接

| 设备 | 配置 / 连接 | 核实状态 |
|---|---|---|
| 开发板 | YD-ESP32-S3 Classic V1.0；通过 USB-C 连接电脑供电 | 根据项目记录及用户此前确认 |
| 控制信号 | ESP32 GPIO6 → MOSFET 模块 TRIG/PWM | 用户此前明确确认 |
| 控制地 | ESP32 GND → MOSFET 模块 GND | 用户此前明确确认 |
| 负载电源输入 | 独立 5V 电源 USB 公头段红线 → VIN+；黑线 → VIN- | 用户此前明确确认 |
| 负载输出 | USB 母头段红线 → VOUT+；黑线 → VOUT-；风扇 USB 插头接入母头段 | 用户此前明确确认 |
| 风扇 | 5V USB 风扇；用户此前提供额定电流约 1A | 额定参数来源仍需以实物标签/说明书复核 |
| 驱动模块 | 蓝色 MOSFET 模块，端子标记 TRIG/PWM、GND、VIN-、VIN+、VOUT-、VOUT+ | 芯片丝印、准确型号及板卡版本未独立确认 |

**接线安全边界：** ESP32 由电脑 USB-C 供电，风扇由独立 5V 电源供电。两路电源不得将正极并接。修改接线前必须断开独立 5V 电源；本记录不代表已完成端子电压、电流或温升测量。

## 3. 软件与测试配置

- 测试源码：本地独立测试文件 `src/test_fan_simple.cpp`
- PlatformIO 环境：`fan-simple-test`
- 控制引脚：GPIO6
- PWM 频率：5000 Hz
- PWM 分辨率：8 bit（0–255）
- PWM 初始化：`ledcAttach(pin, PWM_FREQ, PWM_RESOLUTION)`
- 初始占空比：0
- 连续运行阶段占空比：255（100%）
- 串口波特率：115200
- 连续运行阶段日志：`[Fan-Test] Fan running continuously`

测试程序在初始化时先将引脚设置为 LOW；初始化失败时保持关闭。当前连续运行版 loop 将 PWM 占空比设置为 255，并每秒输出一次运行日志，不再周期性切换为 LOW。

## 4. 实验过程与观察

1. 先前使用 HIGH 3 秒、LOW 3 秒的独立测试循环时，用户观察到风扇每次仅转动约 3 秒，与程序的 HIGH/LOW 周期相符。
2. 随后将独立测试程序的 loop 修改为持续输出 HIGH（PWM 占空比 255），保留初始化及失败保护逻辑。
3. 用户反馈修改后的程序运行后，风扇能够持续转动，不再每 3 秒停止。
4. 用户未提供本次连续运行的精确持续时间、风扇转速测量值或独立保存的串口日志文件。

## 6. 结论

**本次独立硬件测试取得基本成功：** 用户观察到 ESP32-S3 通过 GPIO6 控制 MOSFET 模块后，5V USB 风扇能够启动；将 PWM 占空比设置为 255（100%）后，风扇能够持续运行。

本次结果支持“GPIO6—MOSFET 模块—风扇”控制链路具备基本开关驱动能力，但不等于已完成可调速风扇控制，也不等于正式固件已集成该功能。

### 结论边界

- 100% 占空比只验证全开状态；不能据此证明 20%、50%、80% 等占空比能够稳定控制转速。
- 未测量 GPIO6 电压、MOSFET 输出电压、电流、启动电流或模块温升。
- MOSFET 芯片丝印、模块准确型号、实际电路拓扑和触发阈值仍待独立确认。
- 本次没有完成正式固件、后端或网页端风扇控制集成。
- 当前记录没有附上原始照片、视频或串口日志文件，后续应补充可追溯证据。
