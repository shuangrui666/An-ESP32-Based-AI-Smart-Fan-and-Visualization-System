## 4. 判定规则

- PASS：按可追溯步骤执行，实际结果满足预期，证据可查。
- FAIL：执行后不满足预期，保留失败记录。
- BLOCKED：因硬件、代码、环境或依赖未就绪而无法执行。
- NOT RUN：尚未执行。
- PENDING EVIDENCE：有历史陈述，但缺少足以复现或核验的代码版本/原始证据。

不得将 BLOCKED、NOT RUN 或 PENDING EVIDENCE 写成 PASS。新测试应记录测试版本/Git commit、硬件条件、原始日志和复测关系。
