## 3. 建议测试范围

| 测试类别 | 检查内容 | 当前状态 |
|---|---|---|
| 传感器单测 | 读数有效性、单位、异常值处理 | NOT RUN |
| ESP32 固件 | 启动、读取、命令校验、异常恢复 | NOT RUN |
| 通信 | 连接、断连、超时、无效消息 | NOT RUN |
| 后端 | API 输入校验、存储、错误处理 | NOT RUN |
| AI | 输入范围、模型输出、评价指标 | NOT RUN |
| 前端 | 数据显示、状态更新、控制反馈 | NOT RUN |
| 安全 | 不支持命令拒绝、故障时安全状态 | NOT RUN |
| 整机 | 端到端运行、重复性、稳定性 | NOT RUN |

## 4. 测试判定规则

- PASS：按预先定义的步骤执行，实际结果满足预期，且证据可查。
- FAIL：执行后不满足预期，必须保留失败记录。
- BLOCKED：因硬件、环境或依赖未就绪而无法执行。
- NOT RUN：尚未执行。

不得将 BLOCKED 或 NOT RUN 写成 PASS。若测试条件变化，应建立新测试记录或清楚注明复测条件。
