# SmartFan 2.0 — Web 前端说明

## 1. 项目简介

本目录存放 SmartFan 2.0 的 Web 前端页面，用于展示 ESP32-S3 采集的环境温湿度数据，并提供系统状态可视化界面。

前端使用 HTML、CSS 和 JavaScript 开发，数据图表使用 ECharts。

## 2. 当前已实现功能

- 温度数据展示。
- 湿度数据展示。
- 温湿度数据图表。
- 与 Flask 后端进行数据交互。
- 展示设备及风扇相关状态信息。
- 对尚未接入的风扇硬件，不伪造实际运行状态。

## 3. 功能实现状态

### 已实现的软件功能

- 展示设备及传感器状态信息。

## 4. 当前验证边界

- 前端代码可创建后端控制指令并轮询指令状态；这证明软件请求与状态查询逻辑存在，不代表实体风扇已按网页指令动作。
- ESP32 独立测试程序已通过 GPIO6/MOSFET 使风扇在全开状态连续运行（EXP-012）；该测试没有经过网页和后端，也没有验证中间 PWM 档位。
- 自动控制和远程控制的完整实物闭环仍需在同一次联调中验证。

## 7. 启动方法

### 6.1 启动后端

先在一个终端中启动 Flask：

```powershell
Set-Location "<仓库根目录>\backend"
pip install -r requirements.txt
python app.py
```

后端本地地址：

`http://127.0.0.1:5000`

### 6.2 启动前端

另开一个终端：

```powershell
Set-Location "<仓库根目录>"
python -m http.server 8080 --directory frontend
```

浏览器打开：

`http://localhost:8080`

注意：前端请求的后端地址应与当前实际运行的 Flask 服务地址一致。ESP32-S3 与电脑之间也需要处于能够互相通信的网络环境。
